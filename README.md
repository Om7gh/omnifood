Omnifood - A Learning Project 🍴
Welcome to Omnifood, a fully responsive website built as part of my learning journey through Jonas Schmedtmann’s HTML and CSS Course on Udemy. This project showcases my progress in mastering front-end web development, focusing on HTML5, CSS3, Flexbox, and CSS Grid.

👉 Live Demo: Omnifood on Netlify

About the Project 🚀
Omnifood is a fictional food delivery service website designed to be clean, modern, and fully responsive. It was built from scratch, applying the concepts and techniques I learned throughout the course. The goal was to create a visually appealing and functional website that works seamlessly across all devices.

Key Features ✨
Fully Responsive Design: Works flawlessly on desktops, tablets, and mobile devices.

Modern Layouts: Built using CSS Grid and Flexbox for clean and organized structures.

Interactive Elements: Smooth animations, hover effects, and a sticky navigation bar.

Custom Design: Carefully chosen color schemes, typography, and visual hierarchy to create a cohesive look.

Optimized for Performance: Lightweight and fast-loading, with optimized images and code.

What I Learned 🎓
This project was a huge step forward in my web development journey. Here are some of the key takeaways:

HTML5 & CSS3 Fundamentals: Solidified my understanding of semantic HTML and advanced CSS techniques.

Responsive Design: Learned how to create layouts that adapt to different screen sizes using media queries.

Flexbox & CSS Grid: Mastered these powerful layout tools to build complex, responsive designs.

Design Principles: Explored color theory, typography, and visual hierarchy to create aesthetically pleasing designs.

Best Practices: Wrote clean, maintainable, and reusable code.

Technologies Used 💻
HTML5: For structuring the content.

CSS3: For styling and animations.

Flexbox & CSS Grid: For layout design.

JavaScript: For basic interactivity (e.g., smooth scrolling).

Netlify: For deployment and hosting.

How to Explore the Project 🛠️
Visit the live demo: Omnifood on Netlify.

Open the website on different devices to see its responsiveness in action.

Inspect the code to see how the layout and design were implemented.
